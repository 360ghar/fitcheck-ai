# Plan: Full-platform flow audit, hardening, and de-slop

Status: active
Started: 2026-08-03
Owner: orchestrator (main agent) + parallel sub-agents

## Goal

Walk every page and user flow across the web app (`frontend/`), mobile app
(`flutter/`), and API (`backend/`) as separate, independently-verified workstreams.
For each feature, derive a **user story with expected behaviour straight from the
code**, then verify that behaviour, fix bugs and UX issues, de-slop the
implementation, and harden reliability. End state: the platform is smoother, more
robust, and free of the obvious over-engineering and slop.

## Non-goals

- No schema migrations, no pricing/model changes, no new paid features.
- No architectural rewrites (layers in `ARCHITECTURE.md` stay).
- No Docker; hosted Supabase stays as-is.
- No changes to Apple/Xcode signing material (never-delete list).
- Do not rename public routes or API contracts.

## Acceptance criteria

- [ ] Every page + user flow in web, flutter, backend has a documented user story.
- [ ] Every user story is verified against the code; failures are documented with file:line.
- [ ] Clear bugs and UX errors are fixed and verified (lint/build/test green).
- [ ] De-slop opportunities are applied where safe; the rest are logged as debt.
- [ ] All findings, user stories, and fixes are written into this repo (plan + docs).

## Context / links

- Source reference docs: `SIMPLIFY.md`, `UI_UX_IMPROVEMENTS.md`, `docs/DESIGN.md`,
