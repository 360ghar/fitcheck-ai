## Context

- Before this release: App Store 1.2.0 (14) is live. Play production is
  1.0.5 (10), so Android users skip 1.2.0.
- The release adds `flutter_local_notifications` and native changes in
  `AndroidManifest.xml` and `AppDelegate.swift`. Shorebird cannot patch them.
- Shorebird commands need `SHOREBIRD_TOKEN` from the root `.env`.
- Build scripts: `flutter/scripts/shorebird_release_android.sh`,
  `flutter/scripts/build_ios_release.sh`.

App Store "What's New": `flutter/metadata/release_notes.txt`.

highlights are included:

- A fresh paper-style design with simpler navigation.
