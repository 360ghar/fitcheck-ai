## Decision log

- 2026-09-30: Play blocked build 15 under the photo and video permissions
  policy ("Use alternative system pickers for photos / videos") because
  `AndroidManifest.xml` declared `READ_MEDIA_IMAGES`. `image_picker_android`
  0.8.13 uses the Android Photo Picker on Android 13+, and `gal` needs only
  `WRITE_EXTERNAL_STORAGE` up to API 29, so the permission was removed. Android
  ships as build 16; iOS keeps build 15. Shorebird release `1.2.1+15` for
  Android exists but never shipped on Play.
